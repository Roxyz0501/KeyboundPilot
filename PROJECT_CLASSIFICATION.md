# Classification at task start
New standalone Dalamud plugin, author Roxyz0501. No upstream repository cloned or copied.
Selected in-house configuration persistence and font helpers reused from BaitBeacon; canonical shared tabs copied unchanged.
Game UI layout inspected locally with Lumina; no game executable, sheet, text corpus or art is redistributed.

# First milestone
Read currently displayed ASCII / romanized keywords; type one character at a time with an inclusive random delay between configured minimum and maximum. Default 80–150 ms; allowed 20–5000 ms; equal endpoints give a fixed interval.
No entry, movement, matchmaking, result dismissal or reward exchange automation.
