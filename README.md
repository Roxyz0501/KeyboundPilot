# Keybound Pilot

キーバウンド・ブロウラーの出題を読み取り、キーボード操作で回答する Dalamud プラグインです。通常の自動入力と、回数を指定した「参加申請 → プレイ → 退出」の周回に対応しています。作者: Roxyz0501。

## 簡単な使い方

1. `/keyboundpilot` で画面を開き、「設定」でキー入力間隔の下限・上限、送信後の待ち時間を指定します。
2. **通常プレイ**: コンテンツ内で再生ボタンを押すと開始します。「ゲーム開始時に自動実行」は初期値オンです。
3. **周回**: キーバウンドスクウェアで周回数（1〜9999回）を指定し、循環矢印ボタンを押します。参加申請・突入・自動入力・結果画面からの退出を繰り返し、指定回数で終了します。何周目かと完了回数を画面に表示します。プレイ中に開始した場合は、そのゲームを1周目に数えます。
4. 一時停止ボタンで待機、再生ボタンで再開、停止ボタンまたは Esc、`/keyboundpilot stop` で終了します。プラグイン画面は開始後も開いたままです。停止しても申請済みの参加申請は取り消しません。

日本語IMEを使用できる状態にしてください。読み仮名をローマ字キーで入力し、ひらがなの確定と回答送信を分けて行います。IMEの状態や確定した読みを確認できない場合は、入力済みの文字をBackspaceで削除し、空欄を確認して自動入力を再開します。削除中も入力禁止・フォーカス待ち・手動停止を優先します。

## 主な機能

- 入力対象は **バリア強化 → 詠唱中 → 最も手前の移動中の敵 → その他** の順。近さは画面上の位置による近似です。一度も文字の表示を確認していない出題は選びません。
- フェーズ1〜3の切替や一時的なフォーカス喪失では待機し、結果画面・退出時に自動入力を終了します。別アプリや他の入力欄を操作中はキー送信を待ちます。
- 入力途中で対象が消えたら、残った文字をBackspaceで消し、空欄を確認して次へ進みます。「ゔ」や波線「~」「～」「〜」にも対応します。
- 「動体感知ジャマー」「呪いの視線」は詠唱終了を表示から推定して4秒待機します。対象の詠唱が90%以上まで進んでから消える変化を使います。入力欄が無効な間は4秒後も待機します。「呪いの視線」の4秒は予防待機の設定値で、効果時間の実測値ではありません。他言語の技名・その他の入力禁止技は未対応です。
- 自動入力中は対象コンテンツの操作状態を定期更新します。手動一時停止・停止・退出後には更新しません。移動や追加キーを送らないため、入力禁止待ちに干渉しません。
- キー間隔は20〜5000ms、送信後の待ち時間は0〜60000ms。キー間隔は各文字で抽選し、同じ上下限なら固定です。入力準備・フレーム遅延で実際の間隔が長くなる場合があります。

## 診断ログと設定

**診断ログは初期値オフ**です。「設定」の「診断ログを作成」でオン・オフを切り替えられます。既存設定から更新した場合も初期値はオフです。「診断ログ」タブから記録開始・停止、保存先のコピーもできます。

有効時だけコンテンツ内の状態を記録します。チャット・プレイヤー名・入力欄の文字列・生のキー・認証情報は保存しません。ログの自動送信・既存ログの削除はしません。上限は120分、1回64MiB、合計256MiB、1000ファイルです。100msごとに変化を確認し、最大64KiBのバッファで2秒ごと・退出・終了時に追記します。オフでは診断用の取得・ファイル作成を行いません。

設定は変更時のみ60秒ごとに保存し、ログアウト・通常終了・無効化時に保存を確定します。正常バックアップ3世代を保持します。日本語・English・Deutsch・Français・한국어・简体中文・繁體中文に対応しています。

## 開発・検証・帰属

`tools/Build-Release.ps1` でReleaseビルド・テスト・パッケージ作成を実行します。[VALIDATION.md](VALIDATION.md) に確認済みの範囲と実機検証が必要な項目を記録しています。ゲームデータ・実プレイログ・ホストDLLは同梱しません。

入力はWindowsのキー送信を利用します。周回はゲームの申請機能と対象画面のボタンを操作し、無操作対策は対象コンテンツ内のクライアント操作タイマーを更新します。サーバーパケットを直接送信する処理はありません。

設定保存・フォント補助の一部は [Roxyz0501/BaitBeacon](https://github.com/Roxyz0501/BaitBeacon)（Roxyz0501、Apache-2.0）を参照・再利用しています。共有タブは同一作者の共通テンプレートです。512×512のアイコンはオリジナルで、生成元は `tools/Create-Icon.py` です。

任意の開発支援: [Roxyz0501 / Ko-fi](https://ko-fi.com/roxyz0501)
